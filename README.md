# 東西青果 FAX注文処理システム（試作版）

このリポジトリは、東西青果向けのFAX注文処理システムのPhase 1試作版です。

## 概要

FAXで届く注文書を確認し、A3注文書として整理・印刷するためのデモシステムです。

現在は本番OCRやFAX自動取り込みは未実装で、画面構成・A3レイアウト・確認フローを確認するための試作版です。

## 主な機能

- FAX原本イメージの表示
- OCR読み取り結果の確認・編集
- 左側FAX原本、右側A3注文書の突合せ画面
- A3横向き注文書プレビュー
- 5列版 / 6列版レイアウト切り替え
- A3印刷・PDF保存用レイアウト確認
- 配達日ごとの注文書タイトル表示

## 注意事項

このシステムは試作版です。

実際の顧客情報・本物のFAX画像・個人情報は登録しないでください。
本番運用前には、OCR精度確認、FAX取り込み方法、NAS連携、商品マスター連携、顧客マスター連携などの追加確認が必要です。
